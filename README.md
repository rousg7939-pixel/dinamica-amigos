# 🎉 Dinámica Solidaria - Amigos

Este proyecto es una página web creada con **Next.js** para organizar una dinámica solidaria con números interactivos.

## 🚀 Funcionalidad
- Muestra una cuadrícula de **120 números**.  
- Cada número representa una participación (valor S/10).  
- Los números se podrán marcar como ocupados para evitar repeticiones.  
- Una vez se completen todos, se realizará el sorteo en **TikTok** en la cuenta 👉 [@kassandra_style_studio](https://www.tiktok.com/@kassandra_style_studio).  

## 📦 Tecnologías
- [Next.js](https://nextjs.org/)  
- [React](https://react.dev/)
